# Онбординг YBC — «Стань частиною команди YBC»

Односторінковий сервіс онбордингу для Young Business Club. Немає бекенду й
кроку збірки — це чистий HTML, який Netlify просто роздає.

## Структура

```
ybc-onboarding/
├── public/            ← ТІЛЬКИ це потрапляє на публічний сайт
│   └── index.html     весь сервіс: форма, 5 модулів, тести, Google Sheets
├── apps-script.gs     код для Google Apps Script (не публікується)
├── netlify.toml       налаштування Netlify (publish = "public")
├── .gitignore
└── README.md          ця інструкція (не публікується)
```

> **Важливо:** усе, що лежить у `public/`, стає доступним будь-кому за
> посиланням на сайт. Внутрішні документи компанії туди класти не можна —
> для них є папка `../навчальна база` (вона в `.gitignore`).

## 1. Викласти на Netlify через GitHub (рекомендовано)

Дає автодеплой: змінили контент → закомітили → сайт оновився сам.

**Крок 1. Створити репозиторій на GitHub**
Відкрийте https://github.com/new → назва, наприклад `ybc-onboarding` →
виберіть **Private** (репозиторій приватний, на роботу Netlify це не
впливає) → **не** ставте галочки «Add README / .gitignore» → Create.

**Крок 2. Запушити код** (у PowerShell, з папки проєкту):
```powershell
cd "C:\Сlaud info\ybc-onboarding"
git remote add origin https://github.com/ВАШ_ЛОГІН/ybc-onboarding.git
git push -u origin main
```
Перший `push` відкриє вікно браузера для входу в GitHub — це стандартна
авторизація Git Credential Manager, підтвердіть її своїм акаунтом.

**Крок 3. Підключити Netlify**
netlify.com → **Add new site → Import an existing project** → GitHub →
виберіть репозиторій → налаштування підтягнуться з `netlify.toml`
(build command порожній, publish directory `public`) → **Deploy**.

Netlify видасть посилання типу `https://ybc-onboarding.netlify.app` —
його й розсилайте співробітникам (перейменувати: Site configuration →
Change site name).

**Альтернатива без git:** відкрити https://app.netlify.com/drop і
перетягнути туди папку **`public`** (саме її, не корінь проєкту).
Мінус — кожне оновлення доведеться перетягувати заново.

## 2. Підключити Google Sheets

У вас уже є таблиця для результатів — прив'яжіть до неї скрипт:

1. Відкрийте вашу Google Таблицю.
2. Меню **Розширення → Apps Script**.
3. Видаліть код-заглушку, вставте весь вміст `apps-script.gs`, збережіть.
4. **Розгорнути → Новий деплой** → тип **Веб-додаток**:
   - Виконати від імені: **Я**
   - Хто має доступ: **Будь-хто**
5. **Розгорнути**, підтвердіть дозволи Google.
6. Скопіюйте **URL веб-додатка** (`https://script.google.com/macros/s/.../exec`).
7. У `public/index.html` знайдіть на початку `<script>`:
   ```js
   var SHEET_WEBHOOK_URL = "ВСТАВТЕ_СЮДИ_URL_ВЕБДОДАТКУ_APPS_SCRIPT";
   ```
   і вставте туди скопійований URL.
8. Закомітьте й запуште — Netlify оновить сайт сам:
   ```powershell
   git add -A; git commit -m "Підключено Google Sheets"; git push
   ```

Скрипт сам створить у таблиці вкладку **«Результати»** з колонками
`Дата/час, Ім'я, Посада, Email, Подія, Деталі, Бал/Рахунок`; існуючі
вкладки й дані він не чіпає. Пише рядок при трьох подіях:

| Подія | Коли | Що в «Деталях» |
|---|---|---|
| `start` | введено ім'я/посаду/email | «Розпочав(-ла) онбординг» |
| `module_pass` | пройдено тест модуля | назва модуля, бал X/2 |
| `final_pass` | пройдено фінальний тест | рівень + загальний рахунок |

**Обмеження:** запит іде в режимі `no-cors` (стандарт для статичних
сайтів без бекенду), тому сайт не показує підтвердження запису. Якщо
рядок не з'явився — перевірте пункт 4 («Будь-хто») і що URL вставлено
без пробілів.

## 3. Наповнити реальним контентом

Зараз усі 5 модулів заповнені **заглушками** з позначкою 🔧 — тексти,
посилання на матеріали й питання тестів треба замінити реальними на
основі файлів з папки `навчальна база`.

Усе редагується в одному місці — масив `CASES` на початку `<script>` у
`public/index.html`:

- `doc.summary` / `doc.details` / `doc.takeaway` — тексти модуля;
- `doc.keyTerms` — 3 короткі теги;
- `materials` — посилання `[["Назва", "URL"], ...]` на процеси й
  презентації (самі файли не вантажаться — тільки посилання, напр. на
  Google Docs/Slides);
- `quiz` — 2 питання: `q`, `answers` (4 варіанти), `correct` (текст
  правильної, дослівно як в `answers`), `explain`.

Коли контент стане реальним — приберіть банер «Це чернетка контенту»
(`<div class="draft-banner">`) і чернетку блоку «Що далі».

## Як працює гейміфікація

- Модуль 1 відкритий одразу, модулі 2–5 заблоковані, поки не пройдено
  тест попереднього (поріг: 1 правильна з 2, спроби необмежені).
- Кожен модуль: картка-«файл» → короткий опис → повне досьє (вкладки
  «Документ» і «Презентація») → тест.
- HUD зверху: ім'я, скільки модулів пройдено, бали.
- Після всіх 5 — «Фінальний тест» (10 питань, поріг 70%).
- Після нього — екран «Ласкаво просимо в команду» з рівнем і чек-листом.

Прогрес зберігається в `localStorage` браузера — тобто на конкретному
пристрої людини. Для продовження з іншого пристрою знадобиться бекенд;
це можна додати окремим кроком.
